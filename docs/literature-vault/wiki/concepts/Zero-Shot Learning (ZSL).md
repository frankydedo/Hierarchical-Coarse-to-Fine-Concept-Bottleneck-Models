# Zero-Shot Learning (ZSL)

Zero-Shot Learning (ZSL) is a machine learning paradigm where a model must recognize objects or concepts from classes it has never seen during training. To achieve this, knowledge is typically transferred from "seen" classes to "unseen" classes using auxiliary information, such as semantic attributes, textual descriptions, or word embeddings.
