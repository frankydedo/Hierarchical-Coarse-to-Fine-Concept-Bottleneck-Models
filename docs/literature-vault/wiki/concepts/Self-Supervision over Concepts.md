# Self-Supervision over Concepts

Self-Supervision over Concepts refers to training techniques that allow a model to discover and learn interpretable concepts without explicit manual annotations. This can involve contrastive losses (ensuring images of the same class share similar concepts) or reconstruction losses (ensuring the concepts contain enough information to reconstruct the original image).
