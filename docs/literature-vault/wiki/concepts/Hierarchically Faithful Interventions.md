# Hierarchically Faithful Interventions

Hierarchically Faithful Interventions ensure that when a user corrects or suppresses a concept in a model, that intervention coherently propagates through the semantic hierarchy. For example, suppressing a parent concept like "Animal" will automatically suppress its descendants like "Dog" or "Cat", maintaining logical consistency.
