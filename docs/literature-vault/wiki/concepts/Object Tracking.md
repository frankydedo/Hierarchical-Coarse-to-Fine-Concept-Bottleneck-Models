# Object Tracking

Object Tracking is a fundamental computer vision task that involves locating a moving object (or multiple objects) over time in a sequence of images or video. When combined with interpretable frameworks, tracking can be performed by comparing semantic features (concepts) between consecutive frames rather than relying solely on opaque feature embeddings.
