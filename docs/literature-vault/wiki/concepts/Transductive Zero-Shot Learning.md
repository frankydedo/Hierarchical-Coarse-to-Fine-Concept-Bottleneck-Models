# Transductive Zero-Shot Learning

Transductive Zero-Shot Learning is an extension of standard Zero-Shot Learning where unlabelled data from the "unseen" classes is available to the model during the training phase. This allows the model to adapt and rectify domain shifts between the distributions of the seen and unseen class samples.

**Related Papers:**
- [[Zhang_2019]]: Uses a transductive setting to iteratively align visual and semantic prototypes for unseen classes.
