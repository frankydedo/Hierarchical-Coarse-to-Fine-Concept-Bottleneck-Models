# SUPCBM

SUPCBM (Structured Understanding of leakage Prevention Concept Bottleneck Model) is a CBM paradigm designed to eliminate information leakage. It bypasses the need for a learned label predictor by directly multiplying predicted concept probabilities with a fixed intervention matrix. It relies on a two-level hierarchical concept set (perceptual and descriptive) and uses concept pooling to enforce relevance.
