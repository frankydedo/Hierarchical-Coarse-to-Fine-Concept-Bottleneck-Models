# Concept-based Explainable Artificial Intelligence (C-XAI)

Concept-based Explainable Artificial Intelligence (C-XAI) is a subfield of explainable AI (XAI) that aims to provide explanations for machine learning models using high-level, human-understandable attributes or abstractions (concepts) rather than low-level raw features (like pixels). 

C-XAI methods can be broadly categorized into post-hoc explanation methods (which analyze an already trained black-box model) and explainable-by-design models (like Concept Bottleneck Models, which explicitly incorporate concept representations into their architecture).
