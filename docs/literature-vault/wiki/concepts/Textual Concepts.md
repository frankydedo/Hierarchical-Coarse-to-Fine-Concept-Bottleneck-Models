# Textual Concepts

Textual Concepts are textual descriptions of classes or visual features, typically generated or encoded using Large Language Models (LLMs) or Vision-Language Models (VLMs) like CLIP. By leveraging text embeddings, models can align visual features with complex language descriptions, avoiding the need for strict, manual concept annotation.
