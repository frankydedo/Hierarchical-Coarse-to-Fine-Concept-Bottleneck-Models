# Interpretable Image Recognition with Hierarchical Prototypes

## Summary
The paper introduces HPnet, a model that performs interpretable image recognition by leveraging a predefined taxonomy of class labels. Instead of flat prototypes, it learns [[Hierarchical Prototypes]] corresponding to each parent node in a class tree. This allows the model to explain classifications at multiple levels of abstraction (e.g., animal vs. vehicle, and primate vs. non-primate). The model is also capable of [[Novel Class Detection]], identifying when an image belongs to a coarse class (like animal) but not to any known fine-grained sub-class.

## Key Contributions
- Introduces HPnet, extending prototype-based networks to learn [[Hierarchical Prototypes]].
- Explains classifications at different taxonomical levels.
- Adapts out-of-distribution detection methods for [[Novel Class Detection]] within a hierarchical framework.
- Achieves accuracy on par with black-box models (e.g., VGG-16) while providing localized prototype heatmaps for interpretation.
