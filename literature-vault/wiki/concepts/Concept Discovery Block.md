# Concept Discovery Block

A Concept Discovery Block is a data-driven neural module used to dynamically determine which concepts are active or relevant for a given input. By using amortized Bernoulli sampling to generate binary indicators, the block explicitly filters out irrelevant concepts, enforcing sparsity and facilitating clearer interpretability.

- [[Panousis_2023]]: Utilizes Concept Discovery Blocks at both high and low levels to adaptively select relevant concepts.
