# Low-quality Object Detection

Low-quality Object Detection addresses the challenge of accurately detecting and classifying objects in degraded visual conditions, such as low light, haze, or noise. Traditional approaches involve image enhancement prior to detection, whereas interpretable approaches aim to extract robust semantic representations (like prototypes) that naturally resist these degradations.
