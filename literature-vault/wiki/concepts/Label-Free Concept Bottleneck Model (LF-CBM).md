# Label-Free Concept Bottleneck Model (LF-CBM)

Label-Free Concept Bottleneck Model (LF-CBM) eliminates the need for expensive, manual concept annotations typically required by standard CBMs. It often uses Large Language Models to automatically generate class-level concept descriptions and matches image features with these textual concepts using multimodal models like CLIP.
