# Prototype Regularization Loss (PR-Loss)

Prototype Regularization Loss (PR-Loss) enforces orthogonality or distinctiveness among class prototypes in a high-dimensional feature space. By using techniques like Singular Value Decomposition (SVD), it prevents semantic entanglement and ensures that each prototype represents a highly distinct visual or semantic pattern.
