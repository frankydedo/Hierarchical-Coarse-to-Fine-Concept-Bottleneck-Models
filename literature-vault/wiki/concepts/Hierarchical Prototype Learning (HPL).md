# Hierarchical Prototype Learning (HPL)

Hierarchical Prototype Learning extends standard prototype learning by capturing and organizing class semantics across different levels of abstraction. This can involve multi-scale feature pyramids in object detection, or learning broad (super-prototypes) vs. specific prototypes to bridge domain gaps in zero-shot learning.

**Related Papers:**
- [[Xiang_2026]]: Uses HPL across feature pyramid scales for object detection.
- [[Zhang_2019]]: Uses HPL to bridge visual and semantic spaces in transductive zero-shot recognition.
