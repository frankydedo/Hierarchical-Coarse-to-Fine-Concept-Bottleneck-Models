# Intervention Matrix

An Intervention Matrix is a binary matrix that explicitly defines the allowed relationships between concepts and target classes. By constraining which concepts can influence specific predictions, it acts as a hard structural safeguard against unintended information propagation (concept leakage) and enables straightforward human interventions.
