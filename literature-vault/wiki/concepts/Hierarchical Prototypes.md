# Hierarchical Prototypes

Hierarchical Prototypes extend prototype-based learning by organizing learned visual features according to a predefined taxonomy or class hierarchy. Instead of learning prototypes solely for fine-grained classes, models learn prototypes for parent nodes as well, allowing for explanations at multiple levels of abstraction.

**Related Papers:**
- [[Hase_2019]]: Proposes HPnet to learn hierarchical prototypes for interpretable image recognition and novel class detection.
