# Hierarchical Concept-based Interpretable Models

## Summary
The paper proposes Hierarchical Concept Embedding Models (HiCEMs) to address the limitation of standard [[Concept Embedding Models (CEMs)]], which treat concepts independently. The authors introduce [[Concept Splitting]], a method using Sparse Autoencoders (SAEs) to discover sub-concepts from a pretrained CEM's embedding space without extra annotations. These discovered sub-concepts are then used to train HiCEMs, which explicitly model inter-concept relationships.

## Key Contributions
- **[[Concept Splitting]]:** A technique to discover fine-grained sub-concepts using Sparse Autoencoders on CEM embeddings.
- **[[Hierarchical Concept Embedding Models (HiCEMs)]]:** An architecture that captures hierarchical concept relationships, allowing for test-time interventions at different granularities.
- Introduces PseudoKitchens, a synthetic 3D dataset with precise spatial and concept annotations.
- Demonstrates that HiCEMs maintain high task accuracy while allowing more effective, fine-grained human interventions.
