# Hi-CBM: Mitigating information leakage via hierarchical concept bottleneck modeling

## Summary
The authors present [[Hi-CBM]], a framework designed to combat [[Concept Leakage]] in CBMs. It builds a hierarchical concept set (Perceptual and Descriptive) and uses [[Concept-Bottleneck Pooling]] to filter out irrelevant signals. A binary [[Intervention Matrix]] further governs the concept-to-class mapping to ensure predictions are based only on relevant concepts.

## Key Contributions
- **[[Hi-CBM]]:** Employs a dual-level mechanism to prevent information leakage.
- **[[Concept-Bottleneck Pooling]]:** Selectively aggregates latent features to eliminate spurious concepts.
- **[[Intervention Matrix]]:** A binary matrix that explicitly constrains which concepts can influence which class.
- Extensively evaluated to show high predictive performance and interpretability.
