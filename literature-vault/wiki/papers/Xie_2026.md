# Hierarchical, Interpretable, Label-Free Concept Bottleneck Model

## Summary
The authors present [[HIL-CBM]] (Hierarchical Interpretable Label-Free Concept Bottleneck Model), extending [[Label-Free Concept Bottleneck Model (LF-CBM)|LF-CBMs]] into a hierarchical framework. HIL-CBM predicts labels at different levels of abstraction (basic and subordinate) using concepts of matching granularity. It uses visual consistency and semantic consistency losses to align these levels without requiring explicit relational annotations.

## Key Contributions
- **[[HIL-CBM]]:** Supports hierarchical predictions and explanations across multiple levels of abstraction in both concept and label spaces.
- **[[Gradient-based Saliency Alignment Loss]]:** Enforces visual consistency so that different abstraction layers focus on similar spatial regions.
- **[[Tree-path KL Divergence Loss]]:** Enforces semantic consistency, ensuring predictions follow a valid path in the class taxonomy.
- Provides superior classification performance and human-centric interpretability compared to flat, single-level CBMs.
